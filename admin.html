Entrar

Esta página es pública, pero solo funciona con tu token. No lo compartas con nadie.

¿Cómo creo el token?
  1. En Chrome abre github.com/settings/personal-access-tokens/new (vista de escritorio).
  2. Nombre: ecoenergi-admin. Caducidad: 90 días.
  3. Repository access → Only select repositories → elige ecoenerg.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Generate token y copia el que empieza con github_pat_.

No uses un token clásico con "repo": daría acceso a todos tus repositorios, incluido el privado del bot.

Los cambios se publican al guardar y se ven en la tienda en 1-2 minutos. Los precios mostrados son de ejemplo hasta que pongas los reales.
